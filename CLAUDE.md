# XPEMInventory — Frontend

## Projeto

Frontend Angular do sistema de inventário XPEM.

## Backend

O backend deste sistema fica em um repositório separado:

**Caminho:** `D:\Emanuel\Projetos\UniqueServer\UniqueServer`

Ao iniciar qualquer sessão que envolva trabalho no backend (APIs, rotas, models, etc.), solicite acesso a esse diretório via `request_directory` antes de prosseguir.

## Estrutura

- `src/app/pages/` — páginas da aplicação
- `src/app/services/` — serviços de comunicação com a API
- `src/environments/` — configurações de ambiente (dev/prod)
